## Разработка детерминированного конечного автомата (ДКА)

### Формальное описание автомата
ДКА задается кортежем $M_{DFA} = (Q, \Sigma, \delta, q_0, F)$:
* Множество состояний: $Q = \{q_0, q_1, q_2, q_3, q_4\}$
* Входной алфавит: $\Sigma = \{a, b\}$
* Начальное состояние: $q_0$
* Множество допускающих состояний: $F = \{q_0, q_1, q_2, q_3\}$
* Тупик : $q_4$ (достигается при числе символов $a \ge 4$)

### Таблица переходов функции $\delta(q, \sigma)$

| Состояние | Символ $a$ | Символ $b$ | Пояснение |
| :---: | :---: | :---: | :--- |
| $\to *q_0$ | $q_1$ | $q_0$ | Начальное / Допускающее ($0$ букв $a$) |
| $*q_1$ | $q_2$ | $q_1$ | Допускающее ($1$ буква $a$) |
| $*q_2$ | $q_3$ | $q_2$ | Допускающее ($2$ буквы $a$) |
| $*q_3$ | $q_4$ | $q_3$ | Допускающее ($3$ буквы $a$) |
| $q_4$ | $q_4$ | $q_4$ | Тупик ($>3$ букв $a$) |

## Разработка недетерминированного конечного автомата (НКА)

### Формальное описание автомата
НКА задается кортежем $M_{NFA} = (Q, \Sigma, \delta, q_0, F)$:
* Множество состояний: $Q = \{q_0, q_1, q_2, q_3, q_4\}$
* Входной алфавит: $\Sigma = \{1, 2, 3\}$
* Начальное состояние: $q_0$
* Множество допускающих состояний: $F = \{q_4\}$

Логика автомата основана на недетерминированном выборе шага фиксации контрольного символа:
* $q_0$ — считывание произвольного префикса.
* $q_1, q_2, q_3$ — ветви запоминания первого вхождения символов $1, 2, 3$ соответственно.
* $q_4$ — тупиковое финальное состояние (переход в него осуществляется только при считывании парного символа; отсутствие выходящих переходов гарантирует, что символ был последним в цепочке).

### Таблица переходов функции $\delta(q, \sigma)$

| Состояние | Символ $1$ | Символ $2$ | Символ $3$ |
| :---: | :---: | :---: | :---: |
| $\to q_0$ | $\{q_0, q_1\}$ | $\{q_0, q_2\}$ | $\{q_0, q_3\}$ |
| $q_1$ | $\{q_1, q_4\}$ | $\{q_1\}$ | $\{q_1\}$ |
| $q_2$ | $\{q_2\}$ | $\{q_2, q_4\}$ | $\{q_2\}$ |
| $q_3$ | $\{q_3\}$ | $\{q_3\}$ | $\{q_3, q_4\}$ |
| $*q_4$ | $\emptyset$ | $\emptyset$ | $\emptyset$ |
